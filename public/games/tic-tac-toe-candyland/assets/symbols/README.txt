The game currently renders symbols as emoji (🍭 / 🍬) directly in HTML/JS —
no image files are required to run it.

Drop png files here (lollipop.png, gumdrop.png, lollipop-glow.png, gumdrop-glow.png)
if you'd like to swap emoji for custom art, then update board.js / player.js
to use <img> tags instead of emoji characters.
